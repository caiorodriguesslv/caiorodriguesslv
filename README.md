# 🧑🏽‍💻 Caio Rodrigues

**`Desenvolvedor FullStack`**

Me chamo Caio da Silva Rodrigues, tenho 23 anos e sou natural de Manaus, Amazonas. Atualmente, estou cursando Análise e Desenvolvimento de Sistemas na Fametro (Faculdade Metropolitana de Manaus), onde venho desenvolvendo meus conhecimentos na área de tecnologia da informação. Possuo experiência com desenvolvimento web full stack, atuando em projetos que envolvem tanto o backend quanto o frontend de aplicações.

Trabalho com diversas tecnologias, como Java e Spring Boot para construção de APIs RESTful, Python com Django para desenvolvimento web e automação, e Kotlin para criação de aplicativos móveis Android. No frontend, utilizo Angular para desenvolvimento de interfaces modernas e responsivas. Tenho também experiência com bancos de dados relacionais, como PostgreSQL e Oracle SQL, além de utilizar Docker para conteinerização e padronização de ambientes. No contexto de infraestrutura em nuvem, atuo com serviços da AWS (Amazon Web Services), contribuindo para a escalabilidade e integração de aplicações.

Busco sempre aplicar boas práticas de desenvolvimento, com foco em eficiência, organização e colaboração em equipe, a fim de entregar soluções tecnológicas que gerem valor e impacto real.
